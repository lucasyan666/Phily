# Guide example photos

Drop one JPEG per composition mode into this folder and it appears
automatically as the background of that mode's guide sheet (rebuild the app
after adding files). Any mode without a photo falls back to the painted scene.

## Filenames (must match exactly)

| File                  | Mode             | What to shoot                                              |
| --------------------- | ---------------- | ---------------------------------------------------------- |
| `horizonGrid.jpg`     | Horizon Grid     | Sea/landscape, horizon ~59% down the frame, dead level     |
| `ruleOfThirds.jpg`    | Rule of Thirds   | Person/subject on the TOP-LEFT third intersection          |
| `goldenSection.jpg`   | Phi Grid         | Subject on the top-left phi point (a touch more central)   |
| `goldenTriangles.jpg` | Golden Triangles | Strong diagonal (road/stairs) corner to corner             |
| `fibonacciSpiral.jpg` | Fibonacci Spiral | Curving path/river leading to a subject right-of-centre    |
| `cross.jpg`           | Cross            | Symmetrical, centred subject (doorway, reflection)         |
| `focalMass.jpg`       | Focal Mass       | One small subject, lots of negative space                  |
| `vArrangement.jpg`    | V Arrangement    | Valley / converging lines meeting near centre              |
| `diagonal.jpg`        | Diagonal         | Motion/lines running corner-to-corner                      |
| `radial.jpg`          | Radial           | Hub subject dead centre (flower, tunnel, staircase)        |
| `lArrangement.jpg`    | L Arrangement    | Still life: subject in the left corner, open space right   |
| `compoundCurve.jpg`   | Compound Curve   | S-curve (river/road) foreground → background               |
| `pyramid.jpg`         | Pyramid          | Mountain/group filling a centred triangle                  |
| `circular.jpg`        | Circular         | Round subject centred (plate top-down works best)          |
| `symmetry.jpg`        | Symmetry         | Mirror scene split on the vertical centre line             |
| `aspectRatio.jpg`     | Aspect Ratio     | Any clean landscape (shown inside the 4:5 crop)            |

## Specs

- **Shoot them with Phily** — compose each one on its own guide so the
  subject lands exactly where the overlay says it should. That alignment is
  the whole teaching point.
- Portrait-mode guides show a 3:4 card, landscape guides 4:3 — the image is
  cover-cropped, so keep the subject away from extreme edges.
- Export ~1200px on the long edge, JPEG quality ~80 (keeps the bundle small;
  16 images ≈ 2–3 MB).
- Slightly dark/moody shots read best — the white guide lines and a soft
  scrim are drawn on top.
